# Mtchedlo777 V1.3 — TikTok monitor
Separate Node.js web service; does not replace the existing frontend or Cloudflare Worker.

Render: New Web Service, connect existing repository, root directory `tiktok-monitor`, build `npm install`, start `npm start`, health check `/health`. Use an always-on paid instance for continuous monitoring; free instances sleep. Environment variables: `ADMIN_TOKEN` (same Cloudflare runtime secret), `API_BASE` (existing Worker HTTPS URL), `TIKTOK_USERNAME` (`vajashavelamc`). Never commit secrets. Node 22+. The monitor checks after startup and about 60 seconds after each completed check. It uses the existing `/admin/tiktok` endpoint. Current Worker imposes a minimum expiry of one hour, so an outage can leave the last website status visible for up to an hour. Manual admin changes can be overwritten by next successful poll. The connector is unofficial; failures may occur, and end-to-end testing is required. Health status unknown means check failed; no false offline is sent on thrown errors. No TikTok password or session cookie required by this implementation.
